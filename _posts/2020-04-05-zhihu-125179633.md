<h2>一、概述</h2><p data-pid="HWQU6BrP">Pyomo是一个基于python的开源软件包，它支持多种优化功能，用于制定和分析优化模型。Pyomo可用于定义符号问题、创建具体的问题实例，并使用标准解决程序解决这些实例。Pyomo支持多种问题类型，包括:</p><ul>
<li data-pid="zdQlcQLh">线性规划</li>
<li data-pid="LsXExSYJ">二次规划</li>
<li data-pid="0YrgmuO6">非线性规划</li>
<li data-pid="vSgsRpHk">整数线性规划</li>
<li data-pid="yXit7ZaZ">混合整数二次规划</li>
<li data-pid="qeIhIYwW">混合整数非线性规划</li>
<li data-pid="XFsuaxkA">整数随机规划</li>
<li data-pid="3bwZNnZZ">广义分隔编程</li>
<li data-pid="S9dBJqy8">微分代数方程</li>
<li data-pid="jQP-7_Ad">具有平衡约束的数学规划</li>
</ul><p data-pid="uYlGySiJ">Pyomo支持全功能编程语言中的分析和脚本编制。此外，Pyomo还证明了开发高级优化和分析工具的有效框架。例如，PySP包提供了随机规划的通用求解程序。PySP利用了Pyomo的建模对象嵌入在功能全面的高级编程语言中的事实，这种语言允许使用Python并行通信库透明地并行化子问题。</p><h2>二、安装pyomo和GLPK</h2><p data-pid="z5990dwr">安装pyomo:</p><div class="highlight"><pre><code class="language-text"><span></span>!pip install -q pyomo
</code></pre></div><p data-pid="uPW5swl1">GLPK是一个开源的GNU线性编程工具包，可在GNU通用公共许可证3下使用。GLPK是一个单线程单形解算器，通常适用于中小型线性整数规划问题。它是用C语言编写的，依赖性很小，因此在计算机和操作系统之间具有很高的可移植性。对于许多示例来说，GLPK通常“足够好”。对于较大的问题，用户应该考虑高性能的解决方案，如COIN-OR CBC，它们可以利用多线程处理器。</p><div class="highlight"><pre><code class="language-text"><span></span>!apt-get install -y -qq glpk-utils
</code></pre></div><h2>三、一个简单的例子</h2><h2>1、定义模型</h2><figure data-size="normal"><img src="/assets/blog/images/2120f78d132e809ae9f8.png" data-caption="" data-size="normal" data-rawwidth="606" data-rawheight="290" class="origin_image zh-lightbox-thumb" width="606" data-original="/assets/blog/images/2120f78d132e809ae9f8.png"></figure><p><br></p><div class="highlight"><pre><code class="language-text"><span></span>from pyomo.environ import *


# create a model
model = ConcreteModel()


# declare decision variables
model.x = Var(domain=NonNegativeReals) # NonNegativeReals代表非0实数
model.y = Var(domain=NonNegativeReals)


# declare objective
model.profit = Objective(expr = 40*model.x + 30*model.y, sense=maximize)


# declare constraints
model.demand = Constraint(expr = model.x &lt;= 40)
model.laborA = Constraint(expr = model.x + model.y &lt;= 80)
model.laborB = Constraint(expr = 2*model.x + model.y &lt;= 100)


model.pprint()
</code></pre></div><p><br></p><figure data-size="normal"><img src="/assets/blog/images/ec89c5a0c6bd2374486e.png" data-size="normal" data-rawwidth="1348" data-rawheight="880" class="origin_image zh-lightbox-thumb" width="1348" data-original="/assets/blog/images/ec89c5a0c6bd2374486e.png"><figcaption>model.pprint()</figcaption></figure><h2>
<br>2、求解模型</h2><div class="highlight"><pre><code class="language-text"><span></span>SolverFactory('glpk', executable='/usr/bin/glpsol').solve(model).write()


# display solution
print('\nProfit = ', model.profit())


print('\nDecision Variables')
print('x = ', model.x())
print('y = ', model.y())


print('\nConstraints')
print('Demand  = ', model.demand())
print('Labor A = ', model.laborA())
print('Labor B = ', model.laborB())
</code></pre></div><p><br></p><figure data-size="normal"><img src="/assets/blog/images/65742bb5d3aa64df5ee9.png" data-size="normal" data-rawwidth="552" data-rawheight="386" class="origin_image zh-lightbox-thumb" width="552" data-original="/assets/blog/images/65742bb5d3aa64df5ee9.png"><figcaption>模型结果</figcaption></figure><p></p><p></p>
