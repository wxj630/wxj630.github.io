<p data-pid="NpqfC7vU">上一章我们看的是稳态问题：</p><p data-pid="v79nPs_o"><b>两头条件都给定，空间曲线怎么连起来。</b></p><p data-pid="hQmBfdVH">这一章再往前一步，把时间加回来。</p><p data-pid="mc0EZi0F"><b>一根两头固定温度的热棒，为什么中间一块热斑会慢慢散开，最后整根棒都变平？</b></p><p data-pid="E1dTmTZd">先给一句人话答案：</p><p data-pid="pU8gBMmw"><b>每个点都在和左右邻居交换热量，所以高的地方会往低的地方流。</b></p><p data-pid="sm6DJ4Y-">这就是热传导方程最核心的直觉。</p><p data-pid="BXl8iCwC">偏微分方程的英文是 <code>partial differential equation</code>，简称 <code>PDE</code>。<br>先别急着背，它只是说：</p><p data-pid="HPymnBUD"><b>未知量不只随一个自变量变，而是会同时随空间和时间变。</b></p><p data-pid="GI5bGiqh">这一节的 takeaway：<b><code>PDE</code> 的难点不是更花哨，而是变量从一个方向变成了两个方向。</b></p><h3>0. 先看最小故事</h3><p data-pid="-C7TPxQP">想象一根长度固定的细杆：</p><ul>
<li data-pid="wUYJqtyJ">两端温度被钉死为 0</li>
<li data-pid="MEfocxCJ">中间一开始有一个热包</li>
<li data-pid="eTBMNHbM">热包会慢慢往两边摊开</li>
</ul><p data-pid="q4ZzB0e-">我们想问的不是“某个点现在多热”，而是：</p><p data-pid="7dtG-eBD"><b>整根杆在每个位置、每个时刻到底多热？</b></p><p data-pid="a67gVv4x">这就不是一条曲线了，而是一张“温度场”。</p><p data-pid="lWFbXxnG">这一节的 takeaway：<b>PDE 不是单条时间曲线，而是“位置 + 时间”的二维变化。</b></p><h3>1. 变量和方程</h3><p data-pid="RjKqzOxo">把温度写成 <code>u(x, t)</code>：</p><ul>
<li data-pid="ttxPU7VF">
<code>x</code> 表示空间位置</li>
<li data-pid="Tu7Tss0b">
<code>t</code> 表示时间</li>
<li data-pid="aQwaDKr3">
<code>u</code> 表示这个位置、这个时间的温度</li>
</ul><p data-pid="9K08QPGg">一维热传导方程写成：</p><p data-pid="r3-l-KfF"><img eeimg="2" src="/assets/blog/images/7f82418107fce36d0ebb.svg" alt=" \frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2} "></p><p data-pid="rU6gZnWw">这里：</p><ul>
<li data-pid="_TXq9eqN">
<code>u_t</code> 代表温度随时间怎么变</li>
<li data-pid="pis01_UQ">
<code>u_xx</code> 代表空间上弯得有多厉害</li>
<li data-pid="fUlBejfH">
<code>alpha</code> 是热扩散系数，越大说明热摊得越快</li>
</ul><p data-pid="VvybaAcK">这个方程的人话版本是：</p><p data-pid="wzTUr38p"><b>哪里比周围高，热量就会往外摊。</b></p><p data-pid="NmGLevQc">边界条件通常是：</p><p data-pid="4kdDYPTn"><img eeimg="2" src="/assets/blog/images/061e39a66ae70702b3b6.svg" alt=" u(0,t)=0,\qquad u(L,t)=0 "></p><p data-pid="AbBs6eFG">也就是两端温度固定。</p><p data-pid="9xcZCG3E">初始条件是：</p><p data-pid="j5ZBRY_K"><img eeimg="2" src="/assets/blog/images/fd37d8ba40143d65c73a.svg" alt=" u(x,0)=u_0(x) "></p><p data-pid="AiwwgRFE">也就是一开始那根杆上，温度分布长什么样。</p><p data-pid="jf1lEKFk">这一节的 takeaway：<b>热方程把“空间上的弯曲”直接变成“时间上的变化速度”。</b></p><h3>2. 最小可用例子</h3><p data-pid="6FKXClva">如果一开始中间有一个热包，左右两端是冷的，那么直觉上会发生三件事：</p><ol>
<li data-pid="T2LWsSg-">中间先降温</li>
<li data-pid="xCEbCsEv">两边先升温</li>
<li data-pid="U3Vfg_e6">最后整条曲线越来越平</li>
</ol><p data-pid="3Y3EtTyT">这其实就是“高温向低温扩散”。</p><p data-pid="6mVnu_M5">所以热方程不是在追求某个最优值，而是在描述：</p><p data-pid="7X7Sk4R3"><b>温度如何自动摊平。</b></p><p data-pid="YSyd2Ilv">这一节的 takeaway：<b>热传导的最小工作例子，就是一个中间热、两端冷的杆。</b></p><h3>3. 为什么要离散化</h3><p data-pid="JkQGU3J8">PDE 直接在连续空间上算，通常不好手算。<br>但电脑最擅长的事情是：</p><p data-pid="-ADwA-xY"><b>把连续东西切成一格一格，再反复更新。</b></p><p data-pid="FSAxXF9c">所以最常见的做法是有限差分。</p><p data-pid="w5t4zu5x">有限差分的英文是 <code>finite difference</code>。<br>它的人话版本是：</p><p data-pid="gO3uU1wg"><b>用邻居之间的差，去近似导数。</b></p><p data-pid="g1F_n73D">对于二阶导数，有一个最常用的近似：</p><p data-pid="N4WDuTU0"><img eeimg="2" src="/assets/blog/images/de0fc211c6f113fe8d10.svg" alt=" \frac{\partial^2 u}{\partial x^2}\approx \frac{u_{i+1}-2u_i+u_{i-1}}{\Delta x^2} "></p><p data-pid="A60J3VSx">这句话很重要，因为它告诉我们：</p><p data-pid="V1FDImnt"><b>一个点未来怎么变，只由它左右两个邻居决定。</b></p><p data-pid="PI73K4p2">这一节的 takeaway：<b>PDE 进电脑的第一步，通常是把空间切成网格。</b></p><h3>4. 让时间一步步走</h3><p data-pid="dxd7P6sR">把上面的近似代回热方程，就得到显式更新公式：</p><p data-pid="9awgK0Z8"><img eeimg="2" src="/assets/blog/images/fca4cbe56c90f65e17b5.svg" alt=" u_i^{n+1} = u_i^n + r\left(u_{i+1}^n - 2u_i^n + u_{i-1}^n\right) "></p><p data-pid="S8KdOVv5">其中：</p><p data-pid="ioV-RMDc"><img eeimg="2" src="/assets/blog/images/1a14eaf5cb554a5fcc16.svg" alt=" r = \alpha \frac{\Delta t}{\Delta x^2} "></p><p data-pid="Yg8A_oO_">这里 <code>r</code> 不是什么新术语，你可以先把它理解成：</p><p data-pid="WNqreEe0"><b>时间步长和空间步长拼出来的稳定参数。</b></p><p data-pid="dHww0sKN">如果 <code>r</code> 太大，数值解会炸掉；<br>如果 <code>r</code> 足够小，曲线就会稳稳地摊平。</p><p data-pid="Ol30H1jv">最常见的显式格式里，稳定性通常要求：</p><p data-pid="Xw3HVom2"><img eeimg="2" src="/assets/blog/images/164c610120032c0a225d.svg" alt=" r \le \frac{1}{2} "></p><p data-pid="k1MG-fj-">这一节的 takeaway：<b>PDE 不只是“能不能算”，还要看“步长会不会把结果算炸”。</b></p><h3>5. 代码怎么写</h3><p data-pid="l-mgpIaq">热方程可以直接用 <code>numpy</code> 做网格更新。</p><div class="highlight"><pre><code class="language-text"><span></span>import numpy as np

L = 1.0          # 杆长
alpha = 0.15     # 热扩散系数
nx = 51          # 空间网格点数
dx = L / (nx - 1)

# 选一个稳定的时间步长
r = 0.45
dt = r * dx * dx / alpha

x = np.linspace(0, L, nx)
u = np.exp(-80 * (x - 0.5) ** 2)  # 初始热包
u[0] = 0.0
u[-1] = 0.0

for _ in range(n_steps):
    u_new = u.copy()
    u_new[1:-1] = u[1:-1] + r * (u[2:] - 2 * u[1:-1] + u[:-2])
    u_new[0] = 0.0
    u_new[-1] = 0.0
    u = u_new
</code></pre></div><p data-pid="76NChFSI">这段代码里最关键的是这一行：</p><div class="highlight"><pre><code class="language-text"><span></span>u_new[1:-1] = u[1:-1] + r * (u[2:] - 2 * u[1:-1] + u[:-2])
</code></pre></div><p data-pid="kHN_7yqf">它把“左右邻居”这个物理事实，直接变成了数组切片。</p><p data-pid="PLTioezk">所以这类 PDE 代码的本质不是神秘算法，而是：</p><p data-pid="MjYBcu6r"><b>把公式翻译成网格上的邻居计算。</b></p><p data-pid="qWr8jrNn">这一节的 takeaway：<b>热方程的核心更新，只是在每个网格点上看左右邻居。</b></p><h3>6. 结果怎么看</h3><p data-pid="rpD_BUC8">这个模型的结果应该有三个很清楚的特征：</p><ul>
<li data-pid="PZOgBLvO">热包会变矮</li>
<li data-pid="7qyQfiyP">热量会向两边摊开</li>
<li data-pid="SUtRDkyY">最后曲线会越来越平</li>
</ul><figure data-size="normal"><img src="/assets/blog/images/1a0e21b1370ee697be0e.png" data-caption="" data-size="normal" data-rawwidth="2772" data-rawheight="1100" class="origin_image zh-lightbox-thumb" width="2772" data-original="/assets/blog/images/1a0e21b1370ee697be0e.png"></figure><p data-pid="3p9BCa6J">如果你看到局部温度越来越尖，或者数值突然振荡，通常就是：</p><ul>
<li data-pid="zvUBqYnw">时间步长太大</li>
<li data-pid="59RHOlX3">空间网格太粗</li>
<li data-pid="vEpNgl9c">稳定条件没满足</li>
</ul><p data-pid="rvLfN6KU">所以 PDE 不只是“有没有算出图”，而是：</p><p data-pid="N-u6MdjM"><b>图像是不是符合扩散直觉。</b></p><p data-pid="usY_OeV4">这一节的 takeaway：<b>结果是否合理，第一眼看扩散形状，第二眼看稳定性。</b></p><p><br></p><h3>7. 一个实用判断</h3><p data-pid="RiipVFbX">遇到热方程这类 PDE 时，可以先问三个小问题：</p><ol>
<li data-pid="fKyDvwhc">我是不是已经把空间离散成网格了</li>
<li data-pid="Y1Yr-4Jy">时间步长是不是足够小</li>
<li data-pid="1PeUB5_e">边界条件是不是写对了</li>
</ol><p data-pid="bVwadOlF">如果这三件事都对，热包一般会按预期慢慢散开。</p><p data-pid="TBZi3WRx">如果这三件事有一个错了，图就可能会炸。</p><p data-pid="02J_S4J_">这一节的 takeaway：<b>PDE 的第一层验算，不是高级分析，而是网格、步长和边界。</b></p><figure data-size="normal"><img src="/assets/blog/images/4ff656a900a675cdac80.png" data-caption="" data-size="normal" data-rawwidth="3520" data-rawheight="1980" class="origin_image zh-lightbox-thumb" width="3520" data-original="/assets/blog/images/4ff656a900a675cdac80.png"></figure><h3>8. 小结</h3><p data-pid="hV7W-InA">这一篇压成一句话就是：</p><p data-pid="mOl8Yr3c"><b>偏微分方程描述的是“空间 + 时间”上的变化，热传导方程的数值实现，最常见的方法就是把空间切成网格，再按时间一步步更新。</b></p><p data-pid="tKWqWaN5">如果只记五句话，就记这五句：</p><ul>
<li data-pid="lRTItpIN">
<code>PDE</code> 是 <code>partial differential equation</code>
</li>
<li data-pid="Zw0a9LQ3">
<code>u(x,t)</code> 同时依赖空间和时间</li>
<li data-pid="abnmyIhJ">热方程告诉你哪里高温会往哪里摊</li>
<li data-pid="DySZG4M3">有限差分就是把导数换成邻居差</li>
<li data-pid="NKeuz_64">稳定性比“能不能写出代码”更重要</li>
</ul><p data-pid="8aAz2isp">到这里，我们已经把微分方程从“一个起点往前推”，写到了“边界条件在两头”和“空间时间一起变”。 后面如果再扩，就可以继续往反应扩散、波动方程，或者更贴近建模竞赛的耦合系统去写。</p><h3>参考</h3><ul>
