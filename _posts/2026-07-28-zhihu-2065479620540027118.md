<p data-pid="aEcHPgzj">前几篇我们一直在做一类题：</p><p data-pid="uXsMTA-B"><b>给一个起点，往后推一条曲线。</b></p><p data-pid="20DvsY3W">这一篇换一种更麻烦、也更常见的题：</p><p data-pid="6IT0u6jl"><b>如果题目不是给你一个起点，而是把条件放在两头，你还怎么把中间那条曲线找出来？</b></p><p data-pid="ECYjYBIl">先给一句人话答案：</p><p data-pid="A5xbwOcI"><b>这类题不能只从左边往右走，因为你走到右边以后还得刚好满足右端条件。</b></p><p data-pid="-wOlaiWj">这就是边值问题的核心。</p><p data-pid="8IdmGJCP">边值问题的英文是 <code>boundary value problem</code>，简称 <code>BVP</code>。<br>先别急着背这个缩写，它只是说：</p><p data-pid="pgS2J_3B"><b>你要满足的不止是起点，还有边界。</b></p><p data-pid="UZtdOwmY">这一节的 takeaway：<b>初值问题是“从起点出发”，边值问题是“两头都要对”。</b></p><h3>0. 先看最小问题</h3><p data-pid="Vq5S8uGw">想象一根长度固定的细杆，两端温度都被固定成 0。<br>杆中间有一点加热，所以温度在中间会鼓起来，往两边慢慢降下去。</p><p data-pid="eFVJ_EF8">我们想问的不是“它会怎么随时间变化”，而是：</p><p data-pid="sPD5nb5k"><b>在稳态下，整根杆的温度曲线长什么样？</b></p><p data-pid="s8NXHY8S">这类题很常见：</p><ul>
<li data-pid="3eknz0bu">两端固定温度的导热棒</li>
<li data-pid="yvZqiNQA">两端固定位置的绳子</li>
<li data-pid="hI_u-QtK">两头都定死条件的梁挠度</li>
</ul><p data-pid="Wx4Om-jD">这一节的 takeaway：<b>有些题不是“时间演化题”，而是“空间上怎么连起来”的题。</b></p><h3>1. 变量和方程</h3><p data-pid="PtxTSg-5">我们把空间位置记成 <code>x</code>，温度曲线记成 <code>u(x)</code>。</p><p data-pid="lPOicin7">稳态情况下，最简单的模型可以写成：</p><p data-pid="bPzBOLaq"><img eeimg="2" src="/assets/blog/images/7012fb0892bb03d186db.svg" alt=" \frac{d^2u}{dx^2} = -1 "></p><p data-pid="beNa1dbW">边界条件是：</p><p data-pid="dO-6PXOt"><img eeimg="2" src="/assets/blog/images/6f2ec12124e144440ab4.svg" alt=" u(0)=0,\qquad u(1)=0 "></p><p data-pid="zHm8eMpC">这里的意思是：</p><ul>
<li data-pid="yv5Cc-Y_">左端温度固定为 0</li>
<li data-pid="NpZd_ahv">右端温度固定为 0</li>
<li data-pid="oQsNC2Ek">中间有均匀的“抬高”作用，所以曲线会鼓起来</li>
</ul><p data-pid="nadjrpXx">为什么这个模型好？</p><p data-pid="U_34BQrW">因为它足够简单，但已经包含了边值问题的全部难点：</p><p data-pid="mE3l_5eH"><b>方程在中间，条件在两头。</b></p><p data-pid="74JuV96q">这一节的 takeaway：<b>边值问题的难点不在公式长，而在条件分散在不同位置。</b></p><h3>2. 为什么不能直接像 <code>solve_ivp</code> 那样算</h3><p data-pid="cp0FUVGz">如果这是初值问题，我们只需要知道：</p><ul>
<li data-pid="3we_EZFx">起点在哪里</li>
<li data-pid="_5AIRv_m">起点斜率是多少</li>
</ul><p data-pid="JJFD8-QI">然后就能一路往前推。</p><p data-pid="xYOh8nFZ">可边值问题不一样。<br>你虽然知道 <code>u(0)=0</code>，但你不知道 <code>u'(0)</code> 应该是多少。<br>而右端又要求 <code>u(1)=0</code>。</p><p data-pid="vX6z_ZMs">所以如果你只在左边随便猜一个斜率，曲线大概率会在右边偏掉。</p><p data-pid="so2kpkPx">这就逼出了一个很自然的办法：</p><p data-pid="rYJkfLTK"><b>先猜左边斜率，再看右边对不对，不对就改猜。</b></p><p data-pid="CHGr0Heg">这就是射击法（shooting method）的直觉。</p><p data-pid="1-nxQ9aB">这一节的 takeaway：<b>边值问题不是不能算，而是不能一次把所有条件都同时从左边带过去。</b></p><h3>3. 射击法的想法</h3><p data-pid="TPvObqXC">射击法的人话版本是：</p><ol>
<li data-pid="aht6HYFG">先猜一个左端斜率</li>
<li data-pid="Ax1jAHkt">把它当成初值问题往右算</li>
<li data-pid="mnfuDUMe">看右端边界有没有命中</li>
<li data-pid="CwZA0t3t">没命中就改斜率，再来一次</li>
</ol><p data-pid="33h02ES-">这很像往靶子上射箭：</p><ul>
<li data-pid="3vlaLI-a">你知道靶子在哪里</li>
<li data-pid="3LArCt6G">但你不知道第一箭该抬多高</li>
<li data-pid="1JHfokfn">所以你得试几次</li>
</ul><p data-pid="CNUZlrzR">数学上，我们把二阶方程改成一阶方程组：</p><p data-pid="dK7NKMx5"><img eeimg="2" src="/assets/blog/images/bc454351104b2e3f89bc.svg" alt=" \begin{aligned} u' &amp;= v, \\ v' &amp;= -1 \end{aligned} "></p><p data-pid="m8YhGdoA">这样就能用 <code>solve_ivp</code> 去“猜斜率再积分”。</p><p data-pid="qUT8fdfq">这一节的 takeaway：<b>射击法就是把边值问题拆成“猜斜率 + 初值积分 + 反复修正”。</b></p><h3>4. 直接用 <code>solve_bvp</code>
</h3><p data-pid="XvToWxAY">SciPy 里其实有现成的边值问题求解器，叫 <code>solve_bvp</code>。<br>它做的事就是：</p><p data-pid="L0eRvzGi"><b>直接在两头条件都知道的情况下，把整条曲线找出来。</b></p><p data-pid="mJBvPUBE">对应代码可以写成：</p><div class="highlight"><pre><code class="language-text">def bvp_rhs(x, y):
    # y[0] = u, y[1] = u'
    # u' = v
    # v' = -1
    return np.vstack((y[1], -np.ones_like(x)))


def bc(ya, yb):
    # ya 是 x=0 处的状态，yb 是 x=1 处的状态
    # 两端温度都等于 0
    return np.array([ya[0], yb[0]])</code></pre></div><p data-pid="-FcHZVh-">这里最值得注意的是：</p><ul>
<li data-pid="Wobt4rc1">
<code>ya</code> 代表左端</li>
<li data-pid="DbkCWW71">
<code>yb</code> 代表右端</li>
<li data-pid="HYH0eWCe">
<code>bc</code> 就是 <code>boundary conditions</code>，边界条件</li>
</ul><p data-pid="Jy01eNto">它和 <code>rhs</code> 很像，但不是同一个东西：</p><ul>
<li data-pid="636pSliS">
<code>rhs</code> 负责方程中间怎么变</li>
<li data-pid="sPn5ef-i">
<code>bc</code> 负责两头怎么对</li>
</ul><p data-pid="O7FpxsoY">这一节的 takeaway：<b><code>solve_bvp</code> 不是在猜一个起点，而是在同时满足中间方程和两端边界。</b></p><h3>5. 最小可用例子</h3><p data-pid="FxQeJ3oO">这道题其实有解析解：</p><p data-pid="jIdciEVj"><img eeimg="2" src="/assets/blog/images/3135fd5b4ad0f9794c6d.svg" alt=" u(x) = \frac{x(1-x)}{2} "></p><p data-pid="B9leN1g-">你可以直接代回去验证：</p><p data-pid="nxIZZWil"><img eeimg="2" src="/assets/blog/images/6209ca971ffe5c8750dc.svg" alt=" u''(x) = -1,\qquad u(0)=0,\qquad u(1)=0 "></p><p data-pid="4_CKvSU2">这很好，因为它能拿来检验数值结果有没有跑偏。</p><p data-pid="gNg3wDW_">如果 <code>solve_bvp</code> 算出来的曲线和这个抛物线接近，就说明求解过程是对的。</p><p data-pid="wJmFk7Wn">这一节的 takeaway：<b>边值问题也要尽量找一个最小例子做验算。</b></p><h3>6. 用代码算</h3><p data-pid="OCeAIPJZ">完整脚本可以这样写：</p><div class="highlight"><pre><code class="language-text">import numpy as np
from scipy.integrate import solve_bvp, solve_ivp


def bvp_rhs(x, y):
    # y[0] = u, y[1] = u'
    return np.vstack((y[1], -np.ones_like(x)))


def bc(ya, yb):
    # 左右两端温度都固定为 0
    return np.array([ya[0], yb[0]])


# 先给一个网格和初猜
x = np.linspace(0, 1, 50)
y_guess = np.vstack((0.1 * x * (1 - x), 0.1 - 0.2 * x))

# solve_bvp 直接求解边值问题
sol = solve_bvp(bvp_rhs, bc, x, y_guess)</code></pre></div><p data-pid="0JGSZuYb">这里 <code>y_guess</code> 是初猜，不是最终答案。<br>边值问题通常都需要一个比较像样的初猜，因为求解器要从一个近似曲线慢慢修。</p><p data-pid="4nQSh3Ze">如果你想看射击法，也可以这样做：</p><div class="highlight"><pre><code class="language-text">def shooting_residual(s):
    # 先猜左端斜率 s，把边值问题变成初值问题
    def ivp_rhs(x, y):
        return [y[1], -1.0]

    # 从左端出发，初值是 u(0)=0, u'(0)=s
    sol_ivp = solve_ivp(ivp_rhs, (0.0, 1.0), [0.0, s], t_eval=np.linspace(0, 1, 200))

    # 右端温度离 0 有多远，就是这次射击偏了多少
    return sol_ivp.y[0, -1]</code></pre></div><p data-pid="2SHFW787">射击法的关键不是“猜中一次”，而是：</p><p data-pid="OZWQVmVI"><b>你能不能不断修正那根起始斜率。</b></p><p data-pid="fZ0BTFG2">这一节的 takeaway：<b>边值问题可以直接解，也可以先猜后修正。</b></p><figure data-size="normal"><img src="/assets/blog/images/23f8de3d5e50ea924bdb.png" data-caption="" data-size="normal" data-rawwidth="2772" data-rawheight="1100" class="origin_image zh-lightbox-thumb" width="2772" data-original="/assets/blog/images/23f8de3d5e50ea924bdb.png" data-original-token="v2-17504fc0d5bb58ca8797bd5493203b15"></figure><h3>7. 结果怎么看</h3><p data-pid="ya68AZsZ">这道题的结果应该是一条向上鼓起的抛物线。</p><p data-pid="rki6VR5C">它告诉我们：</p><ul>
<li data-pid="2z4jwojY">两端因为边界条件固定，所以都落在 0</li>
<li data-pid="2CQa8_Nv">中间因为有“抬高”作用，所以会高起来</li>
<li data-pid="tF74Qc7y">整条曲线是被两头条件钉住的</li>
</ul><p data-pid="S-n2tjat">如果你改错了边界条件，形状就会完全不一样。<br>所以边值问题里最容易错的不是求解器，而是：</p><p data-pid="_rCJv-ds"><b>边界条件有没有写对。</b></p><p data-pid="ZKgH1HiZ">这一节的 takeaway：<b>结果形状是否合理，首先取决于边界条件有没有写对。</b></p><figure data-size="normal"><img src="/assets/blog/images/1daab46fc4318e51fae4.png" data-caption="" data-size="normal" data-rawwidth="1600" data-rawheight="900" class="origin_image zh-lightbox-thumb" width="1600" data-original="/assets/blog/images/1daab46fc4318e51fae4.png" data-original-token="v2-8c91f6121e958e610fe45bdacc970bae"></figure><p class="ztext-empty-paragraph"><br></p><h3>8. 一个实用判断</h3><p data-pid="U1LGbaIs">遇到边值问题时，可以先问自己三个问题：</p><ol>
<li data-pid="xnsZiJhf">条件是在起点，还是在两头</li>
<li data-pid="I7CQ5RdG">我是不是把问题误当成了初值问题</li>
<li data-pid="u66a4Ggk">有没有一个简单曲线能先用来验算</li>
</ol><p data-pid="Df2HGHHO">只要这三件事想清楚，<code>solve_bvp</code> 和射击法就不再神秘。</p><p data-pid="OT3ddAlF">这一节的 takeaway：<b>边值问题最怕的不是难，而是把它当成初值问题硬推。</b></p><h3>9. 小结</h3><p data-pid="ZOKhltAU">这一篇压成一句话就是：</p><p data-pid="h11eFWsA"><b>边值问题不是从一个起点往前推，而是要让整条曲线同时满足两头的条件。</b></p><p data-pid="Qx0QTcny">如果只记五句话，就记这五句：</p><ul>
<li data-pid="2M8kyFQB">
<code>BVP</code> 是 <code>boundary value problem</code>
</li>
<li data-pid="QGss93XQ">条件放在两头时，不能只从左边一路算到底</li>
<li data-pid="N3eoPA0U">射击法就是“猜斜率，再修正”</li>
<li data-pid="93QZ9w1e">
<code>solve_bvp</code> 直接处理边界条件</li>
<li data-pid="zPBz6jEr">最简单的验算对象是一条能手算的抛物线</li>
</ul><p data-pid="xHeIlKun">下一篇我们把时间加回来，看看热量在空间和时间里同时变化时，偏微分方程要怎么落到网格上。</p><h3>参考</h3><ul>
