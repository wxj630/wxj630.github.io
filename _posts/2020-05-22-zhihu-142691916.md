<p data-pid="1A3ODGql"><b>运输问题</b>是一类特殊的线性规划问题，一般的运输问题就是要解决：把某种产品从若干个产地调运到若干个销地，在已知每个产地的供应量、每个销地的需求量、各地之间的运输单价的前提下，如何确定一个使得总的运输费用最小的方案。具体的数学模型和笔算求解可以参考中国大学MOOC上<a href="https://link.zhihu.com/?target=https%3A//www.icourse163.org/learn/JXUFE-1002345001%3Ftid%3D1450298456%23/learn/content%3Ftype%3Ddetail%26id%3D1214607174%26cid%3D1218418496" class=" wrap external" target="_blank" rel="nofollow noreferrer">江西财经大学的运筹学课程</a>。这个课程包含了运筹学要求掌握的所有问题，以及这些问题的单纯形法求解、excel求解，因此理论部分的介绍都可以参考这个课程，本文的实践主要基于pyomo和geatpy编程求解。</p><h2>一、产销平衡的运输问题</h2><p from pyomo.environ import *
 
# Creation of a Concrete Model
model = ConcreteModel()


# 定义生产地和销售地
## Define sets ##
#  Sets
#       i   canning plants   / seattle, san-diego /
#       j   markets          / new-york, chicago, topeka / ;
model.i = Set(initialize=['seattle','san-diego'], doc='Canning plans')
model.j = Set(initialize=['new-york','chicago', 'topeka'], doc='Markets')


# 定义生产地的生产量和销售地的需求量
## Define parameters ##
#   Parameters
#       a(i)  capacity of plant i in cases
#         /    seattle     350
#              san-diego   600  /
#       b(j)  demand at market j in cases
#         /    new-york    325
#              chicago     300
#              topeka      275  / ;
model.a = Param(model.i, initialize={'seattle':350,'san-diego':600}, doc='Capacity of plant i in cases')
model.b = Param(model.j, initialize={'new-york':325,'chicago':300,'topeka':275}, doc='Demand at market j in cases')


# 定义生产地到销售地的距离（千英里）
#  Table d(i,j)  distance in thousands of miles
#                    new-york       chicago      topeka
#      seattle          2.5           1.7          1.8
#      san-diego        2.5           1.8          1.4  ;
dtab = {
    ('seattle',  'new-york') : 2.5,
    ('seattle',  'chicago')  : 1.7,
    ('seattle',  'topeka')   : 1.8,
    ('san-diego','new-york') : 2.5,
    ('san-diego','chicago')  : 1.8,
    ('san-diego','topeka')   : 1.4,
    }
model.d = Param(model.i, model.j, initialize=dtab, doc='Distance in thousands of miles')


# 费用/千英里
#  Scalar f  freight in dollars per case per thousand miles  /90/ ;
model.f = Param(initialize=90, doc='Freight in dollars per case per thousand miles')


# cij就是产地i到销地j的单位运价
#  Parameter c(i,j)  transport cost in thousands of dollars per case ;
#            c(i,j) = f * d(i,j) / 1000 ;
def c_init(model, i, j):
 return model.f * model.d[i,j] / 1000
model.c = Param(model.i, model.j, initialize=c_init, doc='Transport cost in thousands of dollar per case')</code></pre></div><p class="ztext-empty-paragraph"><br></p><h2>3、定义变量</h2><div class="highlight"><pre><code class="language-text">定义变量xij：

# supply(i)   observe supply limit at plant i
# supply(i) .. sum (j, x(i,j)) =l= a(i)
def supply_rule(model, i):
 return sum(model.x[i,j] for j in model.j) &lt;= model.a[i]
model.supply = Constraint(model.i, rule=supply_rule, doc='Observe supply limit at plant i')
# demand(j)   satisfy demand at market j ;  
# demand(j) .. sum(i, x(i,j)) =g= b(j);
def demand_rule(model, j):
 return sum(model.x[i,j] for i in model.i) &gt;= model.b[j]  
model.demand = Constraint(model.j, rule=demand_rule, doc='Satisfy demand at market j')</code></pre></div><h2>5、目标函数</h2><div class="highlight"><pre><code class="language-text">## Define Objective and solve ##
#  cost        define objective function
#  cost ..        z  =e=  sum((i,j), c(i,j)*x(i,j)) ;
#  Model transport /all/ ;
#  Solve transport using lp minimizing z ;
def objective_rule(model):
 return sum(model.c[i,j]*model.x[i,j] for i in model.i for j in model.j)
model.objective = Objective(rule=objective_rule, sense=minimize, doc='Define objective function')</code></pre></div><h2>6、模型求解</h2><p data-pid="GZUNO4y6">展示模型结果：</p><div class="highlight"><pre><code class="language-text">## Display of the output ##
